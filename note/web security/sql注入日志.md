# sql注入原理：

对于sql注入来说，底层原理就是进行sql语句的字符拼接

# 防御方式：

1. mysql_real_escape_string()函数防御：
   最基础的防御手段，通过把用户输入的内容进行转义，数据库就只会查找内容。php中写在sql语句拼接之前进行转义操作
2. 限制类型防御：
   如果使用到账号密码登录，可以用$id=(int)$\_POST['id'];进行限制防御
3. 预处理
4. 其他方法：
   白名单，错误信息隐藏，最小权限原则

# sql的局限：

- 对于sql来说，只要能防住普通sql注入就能防住所有sql，而不像xss一样存在多攻击点
- 预处理：
  预处理是一个面向对象的一种处理方式：
  $stmt->execute()执行sql，bind_param()进行绑定参数

# 其他内容：

sql注入之后，拿到的基本上是数据库中第一个用户的信息
