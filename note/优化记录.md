# 项目代码简化

- 在有关jwt的生成和检验逻辑中，把函数和逻辑代码进行了抽离到jwt_function文件中，只需要对函数进行传输payload与密钥，函数进行返回认证结果或存放jwt
- 对于登录状态检测抽离出了一个auth文件，存放对jwt与session不同认证时的逻辑函数吗，在项目代码中只需要引入该文件就能完成对session与jwt认证的身份验证

# 视图与逻辑分离

- 通过变量存放一些情况下应该返回的信息，然后在HTML部分通过php语句进行输出

# 页面美化

- 将session与jwt两种认证方式进行了展示，二者平行的登录方式，将项目代码充分合理的运用起来
- 新增了css文件对登录界面美化
- 新增文件包含页面

# 导航栏结构优化

- 新增导航栏结构
- 浏览器读取文件与php解析文件的区别（因为不同文件深度问题，进行/的跳转获取css文件）

# 输入框以及页面优化

- 更新了vuln文件夹中项目的输入框
- 优化了user界面的布局

# 缓冲区优化

- 对于php反序列化，命令注入，文件包含均使用到缓冲区进行接结果后再统一输出

# jwt工具优化

- 对于弱密钥爆破搭建了新的页面
- jwt生成后在页面直接输出（因为参数较多的原因，需要手动在后端php中修改密钥，身份等信息。）

# 项目漏洞优化

1. session提前生成：在原版本检查密码前生成了session，导致攻击者可以拿错误密码直接生成session后手动访问页面
2. 固定会话攻击：使用session_regenerate_id(true);进行重新生成session
3. hash密码统一使用问题
