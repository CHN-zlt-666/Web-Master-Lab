# 后续扩展方向

## 1. 已有模块深化

### SQL 注入

- 二次注入（Second Order SQL Injection）
- WAF 绕过（大小写、双写、宽字节等）

### XSS

- DOM XSS
- CSP（Content Security Policy）防御与绕过
- XSS 窃取 JWT / Cookie

### 文件上传

- 条件竞争（Race Condition）
- 特殊解析后缀（.phtml、.php5、.phar）
- MIME Type 绕过

### 文件包含

- Session 文件包含
- phar:// 配合反序列化

### 命令注入

- 无回显命令执行（DNSLog 外带）
- Windows 与 Linux 命令执行差异

### PHP 反序列化

- PHAR 反序列化
- ThinkPHP / Laravel 框架反序列化

### SSRF

- gopher:// 协议攻击 Redis
- 云环境 Metadata（169.254.169.254）

### JWT

- RS256 → HS256 算法混淆
- kid Header 注入

## 2. 攻击链深化

尝试将多个漏洞组合形成完整攻击流程，例如：

- SQL 注入 → 文件上传 → 命令执行（RCE）
- XXE → SSRF → 内网资源访问
- JWT 弱密钥 → Token 伪造 → 越权
- XSS → JWT 窃取 → 身份接管
- PHP 反序列化 → RCE → 服务器控制
